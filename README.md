# Nettoyage et Traitement des Données avec Pandas

Ce projet contient des scripts Python pour le prétraitement, le nettoyage et l'imputation de valeurs manquantes ou aberrantes sur des jeux de données à l'aide de la bibliothèque **pandas**.

---

## Fonctionnalités principales

- **Gestion des valeurs aberrantes (Outliers)** : Détection et remplacement des valeurs extrêmes par des valeurs nulles (`NaN`).
- **Imputation des valeurs manquantes** : Remplacement des valeurs manquantes par des mesures statistiques adaptées (médiane arrondie pour les variables numériques, mode pour les variables catégorielles).
- **Fonctions personnalisées** : Implémentation d'algorithmes personnalisés (comme le calcul du mode) adaptés aux structures de données.

---
